双臂协调 ​

使用 Onero A1 左右臂可完成双臂对称动作、独立操作和上层协调任务。

本案例让左臂绘制心形左半边、右臂绘制右半边，共同组成一个心形。DualArm 本身不提供臂间或环境几何避碰，双臂搬运、狭窄空间和桌面任务必须由应用或 MoveIt 规划无碰撞路径。示例默认在 MuJoCo 场景中运行，确认路线无碰撞后，再通过两个独立 CAN 通道连接真机。

两臂先并行到达心形上方起点，再同步发送镜像轨迹，在下方尖点视觉汇合，最后返回镜像工作中心。示例中的关节限位、关节速度和 MuJoCo 接触检查只覆盖当前模型与路线，不能代替真机现场的无碰撞规划。

真机操作提示

本案例会同时驱动 14 个关节。运行前必须核对左右臂型号、CAN 通道、真实基座中心距和运行环境，清空两臂之间及外侧的完整运动空间，并确保紧急停止可用。单臂路径安全不代表两臂组合后不会发生臂间、工具间或环境碰撞。

演示目标与边界 ​

示例依次完成：

  1. 根据右臂心形起点求解 IK，并生成左臂镜像关节目标；
  2. 两臂用 6 秒并行到达心形上方起点，并检查 14 个关节的最大到位误差；
  3. 预计算左右半边心形轨迹，逐点检查关节限位和最大关节速度；
  4. 两条控制线程同时开始发送轨迹，左臂画左半边、右臂画右半边；
  5. 两臂在心形下方尖点视觉汇合并短暂停留，再返回镜像工作中心。

这里的“协调”表示两臂使用镜像关节轨迹、共同起跑屏障和相同采样周期运动；它不代表 SDK 已提供臂间避碰或同步精度保证。路线仍需根据实际现场活动范围自行设计。

示例不控制夹爪，也没有配置 TCP 或负载。安装末端工具后，必须分别配置两臂的 TCP、质量和重心，并重新验证全部路线。

双臂配置 ​

项目左臂右臂
默认型号A1LA1R
默认安装方向humanoid_lefthumanoid_right
默认真机通道can0can1
默认基座位置world Y +0.06 mworld Y -0.06 m

默认 --arm-spacing 0.12 表示左右基座中心距为 0.12 m，因此共享世界坐标系中的左右基座 Y 坐标分别为 +0.06 m 和 -0.06 m。仿真会按该参数移动两个基座，真机则用同一参数建立 world 坐标关系。这个数值必须与真实安装一致；现场中心距、工具或桌面位置不同时，必须传入实测间距并重新完成仿真和接入路径检查。

参数默认值说明

心形轨迹与运行检查 ​

右臂心形起点的 world 坐标为 [0.41, -0.05, 0.05] m，左臂使用镜像关节目标。默认 1× 速度下，动作阶段如下：

顺序动作时长或条件
1并行到达心形上方起点6.0 s；最大关节误差不超过 0.05 rad
2左右臂分别绘制心形左右半边14.0 s
3在下方尖点视觉汇合停留 1.0 s，机械臂仍保留安全间距
4镜像回到工作中心2.0 s

单侧心形轨迹的横向幅度参数为 0.14 m，高度参数为 0.26 m。轨迹发送前，脚本会完成以下检查：

  • 每个心形采样点使用 strict=True 求解 IK；
  • 左右臂所有采样点均处于 A1L／A1R 规格关节限位内；
  • 相邻采样点计算出的最大关节速度不超过 180°/s；
  • 仿真运行期间 MuJoCo 没有检测到接触。

准备和回中阶段使用余弦速度曲线并行运动。连续心形轨迹通过 MotionFrame 和 SDK 的规划执行器发送，并通过线程屏障让两条控制线程同时起跑。示例使用了 _parallel()、_get_ik()、_executor 等私有实现；这些接口可能随 SDK 版本变化，不应将它们当作稳定的公共 API。

成功退出脚本后，两臂仍保持镜像工作中心和使能状态，程序只是关闭通信。close() 不等于 disable()；只有在两臂及负载都得到可靠支撑后，才应主动失能并撤销保持力矩。

结果判断 ​

仿真运行成功应满足：

  • 两臂准确到达心形上方起点，未触发设计的误差阈值；
  • 心形轨迹通过逆运动学、关节限位和速度检查；
  • 两臂分别完成心形两半，并在下方尖点保持可见安全间距；
  • 终端输出“已返回镜像工作中心”；
  • MuJoCo 输出“未检测到碰撞”。

真机终端完成全部阶段，只能说明控制流程正常返回。示例没有测量双臂时间同步误差、路线跟踪误差、臂间距离或接触力，因此不能把该输出当作同步精度或防碰撞验证结果。真机模式不会使用 MuJoCo 接触检测。

常见问题 ​

终端信息原因与处理
Cannot connect to CAN channel 'can0': Interface not available对应 CAN 接口不存在或未启动；先检查设备映射和 ip -details link show can0，不要继续使能
Cannot verify motor state before enableSDK 未收到可验证的电机状态；检查机械臂供电、CAN 通道、左右设备对应关系和反馈，不要反复重试运动
双臂未准确到达爱心上方起点任一关节准备误差超过 0.05 rad；停止演示并检查接入路径、负载、速度和关节反馈
IK did not converge当前起点、基座间距或路线超出稳定可解范围；核对实际安装和目标姿态，重新设计路线，不要只增加迭代次数
左臂/右臂心形轨迹第 ... 点的 J... 超出规格限位预计算轨迹越过关节规格限位；减小心形尺寸或调整起点后重新仿真，不能跳过检查
心形轨迹最大关节速度 ... 超过 180°/s当前倍速或轨迹形状导致采样速度过高；降低 --speed 或重新设计轨迹
新设计路线在仿真中检测到碰撞仿真场景出现接触；检查桌面位置、基座间距和路线，不能跳过检测直接上真机

中断与安全状态 ​

该示例没有把关闭终端或 Ctrl+C 定义为紧急停止流程。真机出现人员进入、异常振动、意外接近或通信异常时，应使用现场已验证的紧急停止方式；不要依赖关闭 MuJoCo 窗口、终端或 CAN 通信来停止机械臂。

进入正式路线前的人工确认只适用于环境保持不变的情况。任一机械臂、桌面、工具或障碍物位置发生变化后，必须重新从基座中心距测量、仿真和接入路径检查开始。
