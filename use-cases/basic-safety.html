基础运动与安全 ​

本案例依次覆盖 MuJoCo 基础运动、真机首次小幅运动、状态监控和减速停止，用于建立从仿真验证到真机安全操作的最小闭环。

真机操作提示

真机示例会使能 Onero A1。运行前必须固定基座和工具、清空完整工作空间、确认型号与 CAN 通道，并确保紧急停止和断电措施可用。stop()、disable() 和紧急停止含义不同；失能前必须可靠支撑机械臂及负载。

演示目标 ​

示例依次验证以下能力：

  1. 在 MuJoCo 中创建 A1R 模型，执行一次关节运动并返回零位；
  2. 连接真机，读取起始关节角并在人工确认后执行一次小幅关节运动；
  3. 以固定频率读取关节角、速度和力矩，不发送运动目标；
  4. 从监控线程调用 stop()，中断一段尚未完成的关节运动。

仿真通过只表示 SDK、模型和基础调用可以运行，不能证明同一目标在实际安装环境中安全。

进入 onero-sdk 仓库并安装仿真依赖：

bash
cd ~/workspace/onero-sdk
source .venv/bin/activate
pip install -e ".[sim]"

运行真机示例前，还需要完成 CAN 接口配置与连接检查，并逐项确认：

  • 机械臂基座和工具已可靠固定，工作空间内无人、无障碍物；
  • 型号与实物一致，示例默认使用 A1R 和 can0；
  • 当前姿态远离关节限位，运动目标与实际安装方向相符；
  • 操作者理解关闭通信不会自动停止运动或让电机失能；
  • 机械臂失去保持力矩时有可靠支撑，供电可以随时切断。

结果判断 ​

运行成功应分别满足：

  • 仿真模型完成目标运动和回零，窗口可正常关闭；
  • 真机首次运动只在人工确认后启动，完成后没有通信或限位异常；
  • 状态监控连续获得 7 关节反馈，没有向机械臂发送运动目标；
  • 安全停止案例在目标完成前停止，且没有把 stop() 误判为失能或紧急停止。

任一真机案例出现方向异常、振荡、通信超时或非预期运动时，应立即使用现场适用的安全措施，不得通过增大目标、提高速度或重复运行绕过异常。

中断与安全状态 ​

stop() 用于中断当前运动并减速停止，电机仍然使能；disable() 会撤销保持力矩；紧急停止用于现场危险情况。三者不能互相替代。

下载版真机首次运动、状态监控和安全停止示例结束时只调用 close()。close() 仅释放通信资源，不等于停止运动或失能。失能前必须分别确认机械臂已经停稳并得到可靠支撑。
