TCP与末端工具 ​

本案例设置法兰到夹爪尖端的几何变换，并让 TCP 沿基座坐标系 +X 移动 2 cm，用于验证笛卡尔运动是否以实际工具作用点为参考。

真机操作提示

错误的安装方向、TCP 或负载参数会使工具实际路径偏离预期。运行前必须测量法兰到工具作用点的真实位姿，固定工具和线缆，清空完整运动空间，并确保紧急停止可用。示例结束时会失能机械臂；失能前必须可靠支撑机械臂及工具。

演示目标 ​

示例依次完成以下流程：

  1. 进入非奇异演示姿态；
  2. 调用 set_tcp() 设置法兰局部 +Z 方向 17 cm 的 TCP；
  3. 在机械臂不动的情况下读取法兰与 TCP 位姿，验证两参考点相距 170 mm；
  4. 保持末端姿态，让 TCP 沿基座坐标系 +X 移动 2 cm；
  5. 展示常见工具的 TCP 参数格式；
  6. 调用 clear_tcp() 恢复以法兰面为参考。

示例中的 17 cm 只用于当前工具，不能替代对实际工具的测量。set_tcp() 本身不会让机械臂运动，只改变 get_pose() 和后续笛卡尔运动使用的几何参考点。

真机运行前还需要完成 CAN 接口配置与连接检查，并确认：

  • can0 连接 A1R 右臂，实体安装方式为 humanoid_right；
  • 法兰中心到夹爪作用点沿法兰局部 +Z 的实测距离为 170 mm；
  • 工具、工件和线缆已可靠固定，完整扫掠路径无障碍；
  • 急停可用，机械臂失能前有人或支架可靠承托；
  • 已按实测值配置工具与工件的总质量和合成重心；TCP 不会自动设置负载。

基座 +X，不是工具 +Z

当前示例没有传入 frame="tool"。目标由当前 TCP 位置加 [0.02, 0, 0] 得到，因此执行的是基座坐标系 +X 方向的运动。

结果判断 ​

运行成功应同时满足：

  • 型号、CAN 通道、安装方向和实际工具尺寸与源码配置一致；
  • 设置 TCP 前后机械臂没有运动，法兰与 TCP 的距离为 170 mm；
  • TCP 理论位置与反馈位置一致，变换计算误差接近 0；
  • 工具作用点沿基座 +X 方向移动约 2 cm，末端姿态保持连续；
  • 反馈位姿与现场观察一致，没有 IK、限位或通信异常；
  • 演示结束后 TCP 被清除，机械臂在得到可靠支撑后正常失能。

终端反馈用于检查示例流程；没有独立测量数据时，不应据此声称笛卡尔绝对精度或重复定位精度。

末端工具边界 ​

配置负责内容不会自动完成
set_tcp()工具作用点的位置和朝向夹爪通信、负载质量和重心
with_gripper=True选择夹爪重力补偿档位根据实际质量建立 payload
end_effector末端工具驱动与动作控制TCP 和负载配置
set_payload()工具与工件总质量和合成重心工具几何和夹爪动作

中断与安全状态 ​

程序正常结束或发生异常时会尝试清除 TCP，并在机械臂仍使能时调用 disable()。disable() 会撤销保持力矩，必须先可靠支撑机械臂和工具。

clear_tcp() 只改变后续运动使用的几何参考，既不会停止当前运动，也不会让电机失能。若工具方向异常、接近障碍物或出现失控趋势，应使用现场适用的紧急停止措施。
