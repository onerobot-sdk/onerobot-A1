MoveIt 2 运动控制 ​

通过 moveit2_a1（https://github.com/switchbot-rd/moveit2_a1）将 Onero A1 接入 MoveIt 2，完成运动规划、碰撞检查，再经 ROS 2 控制器和 onero-sdk 执行机械臂与夹爪动作。

真机操作提示

运行前核对 CAN 通道、安装方向和碰撞环境，清空运动空间。运动命令先去掉 --execute 预览路径，确认后再执行；首次真机验证应降低速度和加速度缩放。真机服务即使设置 allow_execution:=false，仍会使能并保持实测姿态。

安装与配置 ​

使用 Ubuntu 24.04 和已安装 ROS 2 Jazzy 的系统：

bash
git clone https://github.com/switchbot-rd/moveit2_a1.git
cd moveit2_a1
source setup_env.sh
1
2
3

setup_env.sh 自动准备依赖、安装 onero-sdk[dynamics]==0.3.0、构建并加载环境；安装缺失的系统软件包需要系统安装权限。后续每个终端均先进入仓库根目录，执行 source setup_env.sh。

environment.desktop.yaml 用于配置 Onero A1 的实际安装环境，包括桌面、支架等的尺寸与位置。moveit2_a1 中提供的配置仅适用于示例演示的安装环境，运行真机前需按实际安装情况修改。

每次只能启动一套服务：单臂服务或双臂服务，二选一。切换服务或模拟／真机模式前，先结束当前服务。sim 模式模拟关节跟随和夹爪开合，不连接 CAN，也不计算接触动力学。

默认参考系为 world：X 向前、Y 向左、Z 向上；位置目标对应 Link7 法兰，相对位移从当前反馈计算。

单臂控制 ​

启动服务 ​

模拟模式：

bash
ros2 launch onero_a1_moveit_config moveit.launch.py hardware_mode:=sim arm:=right
1

真机模式：

bash
ros2 launch onero_a1_moveit_config moveit.launch.py \
  hardware_mode:=real arm:=right \
  environment_file:="$PWD/src/onero_a1_moveit_config/config/environment.desktop.yaml"
1
2
3

左臂将 arm:=right 改为 arm:=left。CAN 接口不同时通过 can_channel 指定。仅预览时，启动命令添加 allow_execution:=false。

选臂默认 CAN默认安装方向
右臂 rightcan0humanoid_right
左臂 leftcan1humanoid_left

在另一终端加载环境，再运行各项指令：

bash
source setup_env.sh
1

记录与返回起始位置 ​

手臂静止时记录当前位置，不产生运动。相同配置下可沿用已有记录，需要更换起始位置时再重新记录。

bash
ros2 run onero_a1_examples record_startup
1

每项独立运动完成后，返回该位置再进行下一项：

bash
ros2 run onero_a1_examples return_startup \
  --velocity 0.5 --acceleration 0.5 --execute
1
2

以下以右臂为例，左臂参数见左臂参数调整。

单关节抬臂 ​

改变第 1 关节约 34°。

ros2 run onero_a1_examples joint_goal --delta 0.6 \
  --velocity 0.5 --acceleration 0.5 --execute

法兰位置目标 ​

向后 5 cm、向外侧 10 cm、向上 10 cm 到达新位置，多关节共同配合；中途路径可以弯曲。

障碍物避让 ​

在规划场景的原路线中间加入直径 6 cm 的虚拟球体障碍物，规划器重新生成绕行路径，结束后清理球体。可在 RViz 中查看球体位置与规划路径；现场障碍物需另行按实际尺寸与位置配置。

bash
ros2 run onero_a1_examples planning_scene \
  --scene-delta 0.4 --obstacle-radius 0.03 --planning-time 20 \
  --velocity 0.5 --acceleration 0.5 --execute
1

夹爪标定与开合 ​

空载且完整开合范围无遮挡时标定：

bash
ros2 service call /gripper_controller/calibrate std_srvs/srv/Trigger '{}'
1

需要中止标定或当前夹爪动作时，在另一终端执行：

bash
ros2 service call /gripper_controller/stop std_srvs/srv/Trigger '{}'
1

标定完成后，依次全开、半开、全闭：

bash
ros2 run onero_a1_examples gripper --opening 1 \
  --velocity 0.5 --acceleration 0.5 --execute

ros2 run onero_a1_examples gripper --opening 0.5 \
  --velocity 0.5 --acceleration 0.5 --execute

ros2 run onero_a1_examples gripper --opening 0 \
  --velocity 0.5 --acceleration 0.5 --execute

双臂控制 ​

启动服务 ​

模拟模式：

bash
source setup_env.sh
ros2 launch onero_a1_moveit_config dual_moveit.launch.py hardware_mode:=sim
1
2

真机模式：

bash
source setup_env.sh
ros2 launch onero_a1_moveit_config dual_moveit.launch.py \
  hardware_mode:=real \
  environment_file:="$PWD/src/onero_a1_moveit_config/config/environment.dual_desktop.yaml"
1
2
3
4

默认左臂 CAN 为 can1、右臂为 can0，可通过 left_can_channel、right_can_channel 修改。arm_spacing 默认 0.07 米，须与实际安装及环境文件一致。

在另一终端加载环境，运行下面各项指令：

bash
source setup_env.sh
1

双臂服务仅控制单臂 ​

通过 --arm left 控制左臂，另一只手臂保持当前目标。每次选择一项运行；控制右臂时改为 --arm right，镜像抬臂同时将 --delta -0.2 改为 --delta 0.2。

bash
# 第 1 关节抬臂约 11°
ros2 run onero_a1_examples joint_goal --arm left --delta -0.2 \
  --velocity 0.5 --acceleration 0.5 --execute

# 法兰竖直向上走 5 cm
ros2 run onero_a1_examples cartesian_path --arm left \
  --shape line --dx 0 --dy 0 --dz 0.05 \
  --velocity 0.5 --acceleration 0.5 --execute

# 打开单侧夹爪
ros2 run onero_a1_examples gripper --arm left --opening 1 \
  --velocity 0.5 --acceleration 0.5 --execute

记录起始位置与双臂联合运动 ​

两臂静止时同时记录当前位置；该命令不产生运动，已有记录时无需重复执行。

bash
ros2 run onero_a1_examples record_startup --arm both

ros2 run onero_a1_examples dual_joint_goal \

3

每项独立运动结束后，先返回记录位置，再开始下一项：

bash
ros2 run onero_a1_examples return_startup --arm both \
  --velocity 0.5 --acceleration 0.5 --execute

双臂画正方形 ​

两侧法兰从当前位置出发，先向上 10 cm，再各向外侧 10 cm、向下、回到起点，保持各自朝向。两臂同时到达每个角点并短暂停顿；整圈不可达或存在碰撞时不执行。

bash
ros2 run onero_a1_examples dual_cartesian_square --size 0.10 \
  --velocity 0.5 --acceleration 0.5 --execute
1

规划器选择 ​

对同一关节目标分别使用 OMPL / RRTstar、CHOMP 和 STOMP。以下命令只规划，每次选择一条运行。

bash
# OMPL / RRTstar
ros2 run onero_a1_examples joint_goal --delta 0.1 --pipeline ompl --planner RRTstar \
  --velocity 0.5 --acceleration 0.5

# CHOMP
ros2 run onero_a1_examples joint_goal --delta 0.1 --pipeline chomp \
  --velocity 0.5 --acceleration 0.5

# STOMP
ros2 run onero_a1_examples joint_goal --delta 0.1 --pipeline stomp \
  --velocity 0.5 --acceleration 0.5
