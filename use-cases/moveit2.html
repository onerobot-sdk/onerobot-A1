MoveIt 2 运动控制 ​

通过 moveit2_a1（https://github.com/switchbot-rd/moveit2_a1）将 Onero A1 接入 MoveIt 2，完成运动规划、碰撞检查，再经 ROS 2 控制器和 onero-sdk 执行机械臂与夹爪动作。

真机操作提示

运行前核对 CAN 通道、安装方向和碰撞环境，清空运动空间。运动命令先去掉 --execute 预览路径，确认后再执行；首次真机验证应降低速度和加速度缩放。真机服务即使设置 allow_execution:=false，仍会使能并保持实测姿态。

安装与配置 ​

使用 Ubuntu 24.04 和已安装 ROS 2 Jazzy 的系统：

bash
git clone https://github.com/switchbot-rd/moveit2_a1.git
cd moveit2_a1
source setup_env.sh
1
2
3

setup_env.sh 自动准备依赖、安装 onero-sdk[dynamics]==0.3.0、构建并加载环境；安装缺失的系统软件包需要系统安装权限。后续每个终端均先进入仓库根目录，执行 source setup_env.sh。

environment.desktop.yaml 用于配置 Onero A1 的实际安装环境，包括桌面、支架等的尺寸与位置。moveit2_a1 中提供的配置仅适用于示例演示的安装环境，运行真机前需按实际安装情况修改。

每次只能启动一套服务：单臂服务或双臂服务，二选一。切换服务或模拟／真机模式前，先结束当前服务。sim 模式模拟关节跟随和夹爪开合，不连接 CAN，也不计算接触动力学。

默认参考系为 world：X 向前、Y 向左、Z 向上；位置目标对应 Link7 法兰，相对位移从当前反馈计算。

单臂控制 ​

启动服务 ​

目标 ​

启动单臂 MoveIt 2 服务并完成 Onero A1 的规划链路初始化，使后续关节、笛卡尔和夹爪命令可以连接到对应控制器。

模拟模式：

bash
ros2 launch onero_a1_moveit_config moveit.launch.py hardware_mode:=sim arm:=right

真机模式：

ros2 launch onero_a1_moveit_config moveit.launch.py \
  hardware_mode:=real arm:=right \
  environment_file:="$PWD/src/onero_a1_moveit_config/config/environment.desktop.yaml"
1
2
3

左臂将 arm:=right 改为 arm:=left。CAN 接口不同时通过 can_channel 指定。仅预览时，启动命令添加 allow_execution:=false。

3

不带 --execute 时只检查环境。打开窗口后，按住 Shift 操作，松开 Shift 或方向键停止运动，窗口失去焦点时暂停。

按键功能
W / S、A / D、R / F沿 world X、Y、Z 轴前后、左右、上下移动
U / O、I / K、J / L分别绕 world X、Y、Z 轴旋转
Z / X张开／夹取，松键后保持夹持
Tab切换左臂、右臂或双臂，停稳后重新按 Shift
空格 / Enter暂停／恢复
Esc / 关闭窗口退出遥操作，恢复普通轨迹控制

--linear-speed、--angular-speed 分别为法兰线速度（m/s）和角速度（rad/s）。接近运动边界或障碍时会减速或停止，不会自动绕行；遥操作期间不要同时执行其他运动或手动拖动。

轨迹平滑与规划方案比较 ​

从同一起点到同一目标，比较 OMPL、CHOMP、STOMP 的规划耗时、关节路程和预计执行时间，并列出 Ruckig 平滑前后的结果。默认选择平滑后预计执行时间最短的可用方案，在 RViz 预览；添加 --execute 只执行选中的一条方案。

bash
# 比较三个规划器及平滑前后结果，只预览选中的方案
ros2 run onero_a1_examples planning_compare --delta 0.2 \
  --velocity 0.5 --acceleration 0.5

# 只看 OMPL 的平滑效果，目标为 ready 姿态
ros2 run onero_a1_examples planning_compare --pipelines ompl --target ready --jerk 10 \
  --velocity 0.5 --acceleration 0.5

# 按关节路程最短选择并执行一条平滑后的方案
ros2 run onero_a1_examples planning_compare --delta 0.2 --select length \
  --velocity 0.5 --acceleration 0.5 --execute
