真机首次运动 ​

目标 ​

以较长运动时间执行小幅关节运动，验证型号、CAN 通信和基础控制链路。

操作前检查 ​

  • 机械臂基座已固定，工具安装可靠。
  • 工作空间内无人、无障碍物。
  • 供电可随时切断（拔插头或断开 24V）。
  • 模型名与实物一致，CAN 通道正确。
  • 操作人员理解 stop() 与 disable() 的区别。

运行 ​

先审阅并按实际零位修改 SAFE_TARGET：

bash
python examples/getting-started/first_hardware_motion.py
1

脚本不会在结束时自动失能，而是关闭通信，避免机械臂因失去保持力矩而突然下落。若需要失能，先为机械臂提供可靠支撑。
