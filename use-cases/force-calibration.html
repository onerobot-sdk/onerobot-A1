力控与标定 ​

本案例演示力/位混合控制的三种基本场景，并汇总软件零位、动力学、运动学和手眼标定入口。力控和标定都依赖正确的安装方向、TCP、负载、重心与现场基准。

真机操作提示

力控会持续向关节发送力矩，标定流程可能覆盖较大的关节范围。运行前必须固定接触面和标定工装，限制人员接近，检查完整轨迹，并确保紧急停止可用。示例结束时会失能机械臂；失能前必须可靠支撑机械臂及工具。

演示目标 ​

力控示例依次完成以下流程：

  1. 在基座 Z 方向施加 -5 N，持续 3 秒，其余方向保持位置；
  2. 释放 XYZ 三个平移方向，并在 Z 方向施加 -3 N，持续 3 秒；
  3. 注册绕 Y 轴旋转 30° 的倾斜坐标系，沿该坐标系法向施加 -5 N；
  4. 使用兼容旧 API 的 task_frame 重复倾斜面法向力控制；
  5. 退出力控并返回软件定义的关节零位。

标定部分提供独立示例入口，不会在运行 08_force_control.py 时自动执行。

进入 onero-sdk 仓库并安装动力学依赖：

cd ~/workspace/onero-sdk
source .venv/bin/activate
pip install -e ".[dynamics]"

真机运行前还需要完成 CAN 接口配置与连接检查，并确认：

  • 安装方向、TCP、工具与工件总质量和合成重心配置正确；
  • 接触面柔软、固定，不会移动、破裂或夹伤人员；
  • 已用较低目标力和有限持续时间确认坐标轴及力方向；
  • 完整扫掠空间内无人，工具和线缆不会与环境干涉；
  • 操作者理解 force_mode_disable() 只退出力控并恢复位置保持，不会失能。

场景selectionwrench时间说明
Z 轴下压[0,0,1,0,0,0][0,0,-5,0,0,0]3 sZ 轴力控，其余方向位置保持

操作阶段 ​

顺序接口或阶段操作含义
1movej()进入预设接触准备姿态
2场景 1在 Z 方向持续施加 -5 N
3场景 2XYZ 方向柔顺并在 Z 方向施加 -3 N
4场景 3A使用 frame= 指定倾斜面参考坐标系
5场景 3B使用 task_frame= 验证旧 API 兼容性
6movej()返回软件定义的关节零位
7disable()撤销电机保持力矩

每个力控场景结束后都会调用 force_mode_disable()，退出当前力控并恢复位置保持。

标定入口 ​

类型目的示例入口
软件零位建立可复现的用户关节零位软件零位说明
动力学标定辨识惯性和关节摩擦参数动力学标定示例
运动学标定修正关节原点并改善模型一致性运动学标定示例
手眼标定求解相机与法兰或基座之间的变换手眼标定示例

标定文件不得在不同机械臂、序列号、安装方向或工具配置之间直接复用。

结果判断 ​

力控运行成功应同时满足：

  • 三组场景按顺序完成，接触力方向与所选坐标系一致；
  • 进入和退出接触过程平稳，没有振荡、冲击或持续位置漂移；
  • 每个场景结束后退出力控，最后返回关节零位；
  • 终端没有通信、限位或动力学异常。

标定结果还应按类型判断：动力学标定的 residual_rms 是力矩模型拟合残差，不是末端定位精度；运动学标定的 residual_mm 只描述采集触点的模型收敛程度，必须使用独立检测点验证；手眼标定还需要相机内参、同步采集和未参与求解的数据验证。

所有标定结果都应与型号、序列号、左右侧、安装方向、工具、固件和 SDK 版本一起保存。

中断与安全状态 ​

若接触力方向错误、工具滑动、接触面松动或机械臂出现振荡，应立即使用现场适用的安全措施。不能通过增大目标力、延长持续时间或提高刚度来绕过异常。

程序正常结束或发生异常时会调用 disable()；这会撤销保持力矩，不是普通停止。异常发生在力控循环内时，不应仅依赖终端退出判断设备状态，必须现场确认机械臂已经停止并得到可靠支撑。
