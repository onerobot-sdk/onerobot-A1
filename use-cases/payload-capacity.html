本页内容

可配置负载 ​

为 Onero A1 配置工具与工件的总质量、合成重心和安装方向，先在 MuJoCo 中检查负载及运动轨迹，再使用相同参数连接真机完成双向举升动作。

真机操作提示

本案例会连续驱动七个关节。运行前必须实测总质量和合成重心，核对机械臂型号、安装方向和 CAN 通道，清空两侧完整运动空间，并确保紧急停止可用。程序成功结束时会失能机械臂；撤销保持力矩前必须可靠支撑机械臂及负载。

演示目标 ​

示例依次完成以下流程：

  1. 调用 set_payload() 配置负载质量和重心；
  2. 使用中等刚度执行收拢、伸展承载、抬升和收回；
  3. 在另一侧重复相同四个阶段；
  4. 返回本次程序启动时的关节位置；
  5. 成功时失能机械臂并关闭通信。

仿真模式还会把负载加入 MuJoCo 模型。仿真可以检查参数和轨迹，但不包含现场障碍物，不能替代真机碰撞检查、额定负载认证或精度测试。

安装与准备 ​

进入 onero-sdk 仓库并安装仿真、逆动力学依赖：

bash
cd ~/workspace/onero-sdk
source .venv/bin/activate
pip install -e ".[sim,dynamics]"

真机运行前还需要完成 CAN 接口配置与连接检查。默认使用 can0。

mass 必须包含工具和当前工件的总质量；cog 是该组合负载的合成重心，不能只填写工件重心，也不能用 TCP 长度代替。

参数说明 ​

参数是否必填默认值说明
--mass是无工具与工件总质量，单位 kg，不能为负数
--cog X Y Z否0 0 0合成重心在末端 EE 坐标系中的位置，单位 m
--mounting是无实际安装方向，决定基座坐标系中的重力方向
--model否A1R机械臂型号，可选 A1R 或 A1L
--channel否can0真机 SocketCAN 通道
--duration否4.01× 倍速下每段动作的时间，单位 s
--speed否1.0运动倍速；实际每段时间为 duration / speed
--real否关闭添加后连接真机；不添加时运行 MuJoCo

人形肩部垂直安装通常使用：

型号安装参数对应重力方向（base）
A1Rhumanoid_right[-9.81, 0, 0]
A1Lhumanoid_left[-9.81, 0, 0]

upright 只适用于实体基座 +Z 轴确实朝上的安装。安装方向错误会使重力补偿方向错误，可能导致真机振荡、卡住或运动异常。选择 A1L 时，示例会自动镜像关节目标。

动作阶段 ​

顺序终端阶段动作含义
1收拢进入第一侧的收拢姿态
2伸展承载在第一侧伸展机械臂并承载负载
3抬升在第一侧抬升负载
4收回返回第一侧收拢姿态
5～8反向收拢 至 反向收回在 world X 另一侧重复相同过程

八个阶段结束后，程序还会回到本次运行开始时记录的关节位置，而不是固定回到零位。

MuJoCo 仿真 ​

本次录屏使用 2 kg 总负载，重心位于末端 EE 坐标系 Z 正方向 5 cm 处，A1R 按右肩垂直安装，运动倍速为 1.75×。

示例中的--mass 2 --cog 0 0 0.05只用于说明命令格式，运行前必须替换为当前工具与工件的实测数据。

bash
python examples/12_payload_lift.py \
  --mass 2 --cog 0 0 0.05 \
  --mounting humanoid_right --speed 1.75

结果判断 ​

运行成功应同时满足：

  • 启动信息中的质量、重心、型号、安装方向和倍速与实际配置一致；
  • humanoid_right 或 humanoid_left 的 重力(base) 为 [-9.81, 0, 0]；
  • 八个阶段按顺序完成，没有异常或紧急停止信息；
  • 机械臂回到本次运行的初始位置；
  • 终端明确输出“电机已失能”。

如果真机运动方向异常、振荡或卡住，应立即紧急停止，并优先检查 --mounting、--model、负载重心和实际安装方向。不要通过提高倍速、刚度或负载值绕过异常。

中断与安全状态 ​

真机运动过程中发生异常或按 Ctrl+C 时，示例会调用 emergency_stop() 并失能机械臂。紧急停止后应继续支撑负载，检查故障原因；不得直接重新运行。

仿真窗口或通信关闭不等于停止运动。close() 只负责释放通信资源，程序成功路径中的 disable() 才会撤销电机保持力矩。
