运动控制 ​

本案例集中演示关节空间点到点运动、TCP 直线与圆弧运动、单电机位置—速度模式、实时关节伺服和整臂速度控制。

真机操作提示

以下示例会连接 CAN 真机并驱动机械臂或单个电机。运行前必须固定设备、清空完整工作空间、确认目标与实际安装方向相符，并确保紧急停止和断电措施可用。多数示例结束时会失能；失能前必须可靠支撑机械臂或电机负载。

演示目标 ​

六个示例分别验证：

  1. movej()：执行 7 关节目标，读取关节角和力矩后返回零位；
  2. movel()：保持 TCP 姿态，沿基座 X 方向执行 15 cm 直线运动；
  3. movec()：通过经过点和终点执行两条基座 X-Z 平面圆弧；
  4. 位置—速度模式：直接控制单个电机依次到达五个位置目标；
  5. servoj()：以 100 Hz 连续发送正弦关节目标；
  6. speedj()：执行两组恒定关节速度目标，再返回零位。

这些案例用于验证接口行为和运行流程，不构成真机精度、最大速度或连续工作能力测试。

安装与准备 ​

进入 onero-sdk 仓库并安装逆运动学、动力学依赖：

bash
cd ~/workspace/onero-sdk
source .venv/bin/activate
pip install -e ".[ik,dynamics]"

运行前还需要完成 CAN 接口配置与连接检查，并确认：

  • 示例默认使用 A1R 和 can0，型号、通道及安装方向与真机一致；
  • 已按实际工具和工件设置 TCP、总质量与合成重心；
  • 已检查目标点以及目标点之间的完整扫掠空间；
  • 笛卡尔目标远离奇异位形，当前反馈位于 URDF 关节限位内；
  • 实时循环发生超时或上层目标中断时有明确的受控停止策略。

位置—速度模式示例直接创建 Motor，只控制 CAN ID 0x01 的单个电机，不具备整臂运动学、轨迹规划或组合碰撞检查。

结果判断 ​

运行成功应按接口分别判断：

  • MoveJ：7 关节反馈和力矩数组完整，运动后能够返回零位；
  • MoveL：TCP 轨迹近似直线，姿态保持连续，输出目标误差为有限值；
  • MoveC：IK 预检通过，两条圆弧方向和实际缩放符合终端输出；
  • 位置—速度模式：五个单电机目标按顺序完成，最终输出 Done.；
  • ServoJ：两段循环按设定时间完成，没有频率中断或非预期跳变；
  • SpeedJ：两组速度方向与预期一致，最后返回零位。

视频和终端输出只能确认案例流程。没有独立测量数据时，不应据此声称笛卡尔精度、重复定位精度或速度跟踪精度。

中断与安全状态 ​

servoj() 是单帧接口，停止发送后机械臂保持最后一帧目标，不会自动执行受控停止；外部控制器必须处理频率超时、目标中断和异常停止。speedj() 是持续速度控制，运行前必须确认持续时间和整个扫掠空间。

这些示例的结束路径会失能机械臂或电机。失能会撤销保持力矩，不是普通停止，也不是紧急停止。若运行中出现方向异常、接近碰撞、振荡或通信故障，应使用现场适用的安全措施，排除原因后再运行。
