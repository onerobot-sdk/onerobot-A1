模型与控制生命周期 ​

模型 ​

产品型号产品形态与 SDK 入口
A1L7 关节左机械臂；Arm("A1L", ...)；1 路 CAN
A1R7 关节右机械臂；Arm("A1R", ...)；1 路 CAN
A1SA1L + A1R 双臂套装；DualArm.create(...)；2 路 CAN

A1S 是双臂产品型号，不是一条 14 关节的单臂。SDK 仍以 7 关节 Arm 为基本单元，使用 DualArm 组合左右两臂，因此不应使用 Arm("A1S", ...)。双臂的通道、共享 world 坐标系和安全边界详见双臂控制。

角度使用弧度，角速度使用 rad/s，位置使用米，力和力矩分别使用牛顿和牛顿米。

接口中常见的数据可以按下表区分：

数据典型字段或参数单位用途
关节位置joints、movej()rad描述单臂 7 个关节的姿态；A1S 左右臂分别传入 7 个值
关节速度velocities、speedj()rad/s描述或控制关节运动速度
TCP 位置position、get_pose()m描述末端位置
TCP 姿态rotation、poserad 或旋转矩阵描述末端方向
力与力矩torques、wrenchN、N·m读取反馈或配置力控目标

生命周期 ​

单臂 ​

  1. 创建 Arm 并选择唯一后端：channel、backend 或 can_bus 三选一。
  2. 调用 enable() 进入可控状态。
  3. 发送运动或状态查询指令。
  4. 使用 stop() 中断运动，必要时切断电源。
  5. 仅在机械臂已得到可靠支撑时调用 disable()。
  6. close() 关闭通信资源，默认不失能。

后端的选择决定数据从哪里来，但不改变上层主要运动接口：

后端构造方式是否连接 CAN适合用途
MuJoCobackend=MujocoBackend(...)否模型、轨迹和接口验证
SocketCANchannel="can0"是真机控制和反馈读取
自定义后端backend=...取决于实现集成外部控制器或测试环境

同一段代码在不同后端运行前，仍需重新检查模型、安装方向、负载和安全条件。

A1S 双臂 ​

阶段单臂 ArmA1S DualArm
创建创建一个 A1L 或 A1R，绑定一个后端创建 A1L 和 A1R，绑定两个独立 CAN 通道并设定两臂基座位置
使能arm.enable()dual.enable() 依次使能两臂；右臂失败时会回滚失能左臂
控制通过 arm 发送单臂目标通过 dual 并行发送双臂目标，或通过 dual.left / dual.right 单独控制
停止运动arm.stop()当前无统一 dual.stop()；应进入双臂安全处理流程并分别停止、确认两臂状态
失能已可靠支撑后调用 arm.disable()两臂和负载均已可靠支撑后调用 dual.disable()
释放通信arm.close()退出 DualArm 上下文时分别关闭左右臂通信，默认不失能

DualArm 的并行调用不是硬实时同步器，也不提供臂间或环境几何避碰。任意一侧异常时，不能假设另一侧会自动停止。

术语区别

  • 停止运动：stop()，尽量减速至静止并保持控制。
  • 失能：disable()，电机不再提供维持姿态所需的力矩，机械臂可能下落。
  • 紧急停止：emergency_stop() 立即失能所有电机（之后需 enable() 恢复），不应与普通停止混用。

生命周期动作对照 ​

动作是否停止当前运动是否撤销保持力矩是否释放通信资源典型用途
stop()是否否正常中止任务或处理可控异常
disable()是是否已可靠支撑后撤销电机力矩
close()不作为停止流程使用默认否是释放 SDK/总线资源
close(disable=True)结束时失能是是已确认支撑条件下关闭会话
emergency_stop()紧急中止是取决于后续关闭人员或设备立即处于危险状态

程序退出、浏览器关闭和网络断开都不是现场安全动作。应用应把运动中止、失能和资源释放明确写在不同的分支中，并在异常路径中先处理机械臂状态。

上下文管理器 ​

with Arm(...) 和 with DualArm.create(...) 都会调用 enable()，退出时关闭通信；它们都不会默认失能。这一行为用于避免带重力负载的机械臂突然下落。

因此，推荐把资源释放写在 finally 中，并明确区分三个动作：运动中止使用 stop()，通信资源释放使用 close()，确认机械臂有可靠支撑后才使用 disable()。不要把异常退出、网页关闭或 Python 进程结束当作安全停止流程。

最小控制骨架 ​

python
from onero_sdk import Arm, OneroError

arm = Arm("A1R", channel="can0")
try:
    arm.enable()
    # 在此发送已经过现场确认的运动目标。
except OneroError:
    arm.stop()
    raise
finally:
    # close() 只释放通信；仅在机械臂可靠支撑后才使用 close(disable=True)。
    arm.close()
