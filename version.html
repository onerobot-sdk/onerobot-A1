项目当前基准

Onero SDK0.3.0
Python3.10 及以上
文档语言简体中文

本文档仓库不包含 SDK Python 包。SDK 可从 PyPI 安装，源码位于 GitHub。安装时应选择与文档匹配的发布版本；若 API 行为不一致，以实际安装版本的源码和发布说明为准。

能力标记 ​

  • 核心功能：仅依赖 numpy 的常规接口。
  • 可选功能：需安装 [ik]、[dynamics]、[sim] 或 [trajectory] 等额外依赖。
  • 真机功能：需要 CAN 设备、电源和正确接线，文档构建不会验证真机结果。
