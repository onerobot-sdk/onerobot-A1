文档范围 ​

本文档介绍 Onero A1 机械臂 Python SDK 的安装、配置、运动控制和典型应用。当前内容以 SDK v0.3.0 为基准，支持 A1L 与 A1R 模型。

真机操作提示

机械臂运动前应清空工作空间，并以较低速度完成首次验证。close() 或退出上下文只关闭通信资源，不会自动让电机失能；失能前必须为机械臂提供可靠支撑，防止机械臂因重力下落。

获取 SDK ​

  • PyPI：https://pypi.org/project/onero-sdk/
  • GitHub：https://github.com/lvwenyi01/onero-sdk
bash
pip install onero-sdk
1

需要 MuJoCo 仿真时安装：

bash
pip install "onero-sdk[sim]"
