双臂控制 ​

双臂控制不仅要同时管理两个 Arm，还要统一世界坐标、区分左右型号与通信通道，并处理同步、碰撞和异常停止。建议先分别验证左右单臂，再执行双臂联动。

能力作用主要接口
创建与生命周期按左右侧默认配置创建、使能和失能两臂DualArm.create()、enable()、disable()
共享世界坐标设置两基座位置，在同一坐标系中读取位姿arm_spacing、base_position_left/right、get_poses()
并行目标运动同时执行左右关节或笛卡尔目标movej()、movel()、home()
单帧实时控制同时发送一帧左右关节目标servoj()
单臂高级功能分别使用速度、力控、示教、TCP 和负载接口dual.left、dual.right

真机操作提示

单臂轨迹安全不代表双臂组合安全。DualArm 不提供臂间或环境几何避碰，也不保证任意一侧异常时另一侧会同时停止。真机运行前必须检查两臂、末端工具、线缆、工件和环境之间的完整扫掠空间，并确保可同时停止两臂的现场安全措施可用。

基础配置 ​

双臂必须使用独立通信通道，并在同一个 world 坐标系中设置真实基座位置：

python
from onero_sdk import DualArm

dual = DualArm.create(
    left_channel="can0",
    right_channel="can1",
    arm_spacing=0.12,
)

try:
    dual.enable()
    dual.movej(
        left_joints=[0.0] * 7,
        right_joints=[0.0] * 7,
        duration=3.0,
    )
finally:
    # 只有两臂及负载都受到可靠支撑时才能失能。
    dual.disable()

左右臂的同名关节不一定具有相同正方向。镜像动作应使用明确的左右映射规则并在仿真中验证，不能直接复制关节数组。

双臂任务的职责划分 ​

创建 DualArm 只建立两臂对象和共享坐标关系，不会自动完成以下工作：

范围必须确认的内容常见遗漏
左右单臂型号、通道、安装方向、TCP、负载和关节限位只配置一侧工具，或照搬另一侧参数
共同坐标系两个基座位置、world 方向和任务目标把两臂各自的 base 目标当作同一个空间点
共同工作空间两臂、工具、工件和线缆的碰撞风险只验证单臂路径，不验证组合路径
同步与异常启动顺序、超时、双侧停止和恢复策略一侧异常后另一侧仍继续执行

双臂的第一条真机任务应避免两臂靠近、交叉路径或共同搬运。先用仿真验证 world 坐标和方向，再以分离、小幅、低速目标验证两臂状态。

控制节奏与停止 ​

接口控制节奏使用边界
dual.movej()、dual.movel()、dual.home()两个阻塞式操作在线程中并行执行，等待两侧结束后返回并行调用不等于硬实时同步，也不包含碰撞检查
dual.servoj()每次只发送一帧左右关节目标调用方负责固定频率、超时和循环退出
dual.left、dual.right分别调用两个单臂接口应用层必须自行协调开始时刻和异常处理

DualArm 当前没有统一的 stop() 方法。任意一侧通信异常、目标不可达或接近碰撞时，应用必须进入统一的双臂安全处理流程，停止两侧任务并分别确认状态；不能假设并行接口会自动中止另一侧。

stop()、disable() 和紧急停止含义不同：停止运动后机械臂仍然使能，失能会撤销保持力矩，现场危险则应使用已经验证的紧急停止方式。两臂停止后，要分别确认是否停稳、是否仍使能以及是否得到可靠支撑。

推荐验证顺序 ​

  1. 分别读取左右臂状态，核对型号、CAN 通道和关节方向；
  2. 分别执行远离共同工作区的小幅单臂运动；
  3. 在 MuJoCo 中验证基座位置、world 方向和双臂组合路径；
  4. 在真机上以分离、小幅、低速目标验证并行运动和双侧停止；
  5. 完成以上检查后，再逐步引入工具、负载、交叉路径或共同搬运。
