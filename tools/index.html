TCP、负载与末端工具 ​

安装夹爪、吸盘、焊枪或相机后，需要分别配置工具的几何关系、动力学参数和控制驱动。三者作用不同，不能相互替代。

配置解决的问题主要接口
TCP工具作用点在哪里、朝向哪里set_tcp()、clear_tcp()
负载工具和工件的质量、重心在哪里set_payload()
末端工具如何使能和控制夹爪、灵巧手等设备end_effector、arm.gripper

真机操作提示

TCP 或负载参数错误会使工具路径、法兰路径和动力学估计偏离预期。首次验证应清空工作空间、降低运动幅度，并准备好紧急停止。示例结束时会执行 disable()；失能会撤销保持力矩，必须先可靠支撑机械臂。

TCP 工具中心点 ​

TCP（Tool Center Point）是工具实际作用点，例如夹爪指尖中心、吸盘中心或焊枪尖端。set_tcp() 定义的是法兰坐标系到工具坐标系的变换：

text
T_base_tcp = T_base_flange × T_flange_tcp
1

其中 T_base_flange 由正运动学计算，T_flange_tcp 由 set_tcp() 设置。若机械臂启用了世界坐标系，公式中的 base 对应替换为 world。

python
arm.set_tcp(
    position=[0.0, 0.0, 0.15],
    rotation=[0.0, 0.0, 0.0],
)

参数含义单位与格式
position从法兰原点到 TCP 原点的平移，在法兰坐标系中表达米，[x, y, z]
rotation从法兰坐标系到工具坐标系的旋转；省略时两坐标系方向一致旋转向量 [rx, ry, rz]（rad），也支持四元数或 3×3 旋转矩阵

TCP 相关接口 ​

接口功能及与 TCP 的关系
set_tcp(position, rotation=None)设置法兰到 TCP 的位置和方向。重复调用会替换当前配置，不会累加；只改变坐标变换，不会使机械臂运动或自动配置负载。
clear_tcp()清除 TCP，恢复以法兰为末端参考点，并使 frame="tool" 不可用；不会停止运动或使机械臂失能。
get_pose()设置 TCP 后返回 TCP 位姿，而不是法兰位姿。可读取基座、世界或自定义坐标系中的位姿，但不支持 get_pose(frame="tool")。
movel()直线运动目标按 TCP 解释；frame="tool" 时，位置和旋转表示当前工具坐标系中的相对运动。
movep()目标位姿按 TCP 解释，通过关节空间插值到达目标，不保证 TCP 路径为直线。
movec()圆弧运动的途经点和目标点按 TCP 位姿解释。
servop()实时笛卡尔目标按 TCP 解释；frame="tool" 时目标为当前工具坐标系中的相对运动。
speedl()控制 TCP 的笛卡尔速度；frame="tool" 时速度分量沿当前工具坐标轴表达。
force_mode()配置 TCP 后会计入 TCP 到法兰的力臂；frame="tool" 时力和力矩沿工具坐标轴表达。
get_external_wrench()可通过 frame="tool" 获取在 TCP 作用点、工具坐标系中表达的外力和力矩估计。
movej()接收关节角目标，不受 TCP 几何偏移影响。

不要把工具 Z 轴当成基座 Z 轴

position=[0, 0, 0.15] 表示沿法兰 Z 轴偏移 15 cm。它在基座坐标系中的实际偏移为 R_base_flange @ [0, 0, 0.15]，通常不是 [0, 0, 0.15]。

IK 不收敛时先检查 ​

如果 movel() 报 IK did not converge，优先检查以下项目：

  • 是否从全零伸直等奇异位形开始；先用 movej() 到非奇异准备姿态；
  • 绝对 TCP 目标是否过远或超出工作空间；先从当前位置做 2～5 cm 小幅运动；
  • 是否遗漏目标姿态；仅验证平移时应读取并保持当前 TCP 姿态；
  • TCP 偏移、安装方向和左右臂型号是否与真机一致；
  • 路径中间点是否经过关节极限或奇异区，而不只是最终目标是否可达。

单纯增加 IK 迭代次数不能解决不可达目标、奇异起点或错误姿态约束。

负载配置 ​

set_payload() 配置工具与当前工件的总质量和合成重心，供重力补偿、碰撞检测阈值和外力估计使用：

python
arm.set_payload(mass=0.8, cog=[0.0, 0.0, 0.08])
1
参数含义
mass工具与工件总质量，单位 kg
cog合成重心相对 SDK 末端 EE 坐标系的位置 [x, y, z]，单位 m；省略时为 [0, 0, 0]

负载配置会替换上一次配置，不会叠加。更换工具、抓取工件或释放工件后都应重新设置。TCP 和负载相互独立：set_tcp() 不会更新质量或重心，set_payload() 也不会改变运动参考点。

负载能力与负载参数不是同一概念

调用 set_payload() 不会提高机械臂允许承载的上限。最大负载、允许重心范围和不同负载下的精度必须以经过确认的真机测试数据为准；本页暂不填写未经验证的指标。

负载动力学功能需要安装：

末端工具驱动 ​

end_effector 用于把夹爪、灵巧手等驱动与机械臂组合。传入末端工具后，arm.enable() 和 arm.disable() 会同时调用工具对应的使能与失能方法；夹爪也可通过 arm.gripper 访问。

python
from onero_sdk import Arm, OmniPickerGripper

gripper = OmniPickerGripper(can_id=0x08, force=0x20, velocity=0xFF)
arm = Arm(
    "A1R",
    channel="can0",
    end_effector=gripper,
    with_gripper=True,
)

arm.enable()
arm.gripper.open()
arm.gripper.set_position(0.5)  # 0.0 全闭，1.0 全开
arm.gripper.grasp()

配置末端工具时应分别确认：

项目作用是否自动配置其他项目
end_effector通信、使能和动作控制不会自动设置 TCP 或负载
with_gripper=True选择经过验证的夹爪经验重力补偿曲线不会推断夹爪质量或重心
set_tcp()设置工具几何参考点不会控制夹爪或修改动力学
set_payload()设置已测得的总质量和重心不会改变工具几何或通信

close() 默认只释放通信资源，不等于失能。只有在机械臂已可靠支撑、明确需要撤销力矩时才调用 disable() 或 close(disable=True)。
