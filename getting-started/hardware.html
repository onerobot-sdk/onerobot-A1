连接真机 ​

开始前

固定机械臂基座，清空工作空间。首次运动应降低速度，并安排观察人员随时准备切断供电。

本章按“核对物料 → 首次部署与 CAN 映射 → 只读连接检查 → Debug UI 确认链路 → 首次运动”的顺序进行。机械臂本体安装与接线图见机械臂安装。

1. 物料清单 ​

物料用途说明
机械臂本体执行机构按订单为 A1L（左）或 A1R（右）或 A1S（双臂）
支架与支架配件固定机械臂基座组装与固定见机械臂安装
扳手及螺钉安装紧固随安装配件提供
支架固定配件将支架固定在台面常见为 C 型夹，按台面形式选用
DC 48 V 电源及电源线为机械臂供电供电能力至少 6 A；以随箱说明和设备铭牌为准
USB-CAN 适配器主机与机械臂的 CAN 通信双臂配置时每条臂各用一个
末端工具（夹爪等）抓取与作业选配，裸法兰配置不需要
随箱说明与清单核对型号、线序和供电规格以随箱文档为准

数量、型号和线缆以随箱清单为准；发现外观损伤或配件缺失时先不要上电。各物料的外观与名称可对照机械臂安装中的演示视频。

2. 首次部署与 CAN 映射 ​

首次连接真机需要完成两件事：安装 onero-sdk 虚拟环境，并把 USB-CAN 适配器映射成 Linux CAN 接口。完整过程见下面的演示视频：

SDK 安装、版本确认与可选依赖见安装与仿真。

CAN 接口速率固定为 1 Mbit/s，按实际适配器选择对应的配置方式。原生 SocketCAN 适配器：

bash
sudo ip link set can0 down 2>/dev/null || true
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up
ip -details link show can0

串口转 CAN 适配器（slcand，设备节点按实际连接修改）：

bash
sudo slcand -o -c -s8 /dev/ttyACM0 can0
sudo ip link set can0 up

-s8 表示 1 Mbit/s。持续高频下发指令时，建议同时提高发送队列长度：

bash
sudo ip link set can0 txqueuelen 1000
1

不同 USB-CAN 适配器可能需要额外驱动或不同的设备节点，请以设备说明为准。

3. 确认型号与通道 ​

  • 右臂使用模型名 A1R。
  • 左臂使用模型名 A1L。
  • channel 是 Linux SocketCAN 接口名，例如 can0，它不用于推断左右臂型号。

4. 只读连接检查 ​

get_state() 只读取电机反馈，不会使能电机，也不会让机械臂运动，可以在上电后立即执行：

python
from onero_sdk import Arm

arm = Arm("A1R", channel="can0")
try:
    state = arm.get_state()
    print(state.joints)
finally:
    # 未使能，关闭通信即可，无需失能。
    arm.close()

5. 使用 Debug UI 确认链路 ​

只读连接检查通过后，再启动 Debug UI 观察状态：

bash
python -m onero_sdk.debugui --arm right --channel can0
1

打开 http://localhost:8090，先确认关节状态持续刷新且没有通信错误，再考虑让机械臂运动。启动与操作演示见 Debug UI。

6. 首次运动 ​

请按真机首次运动案例逐项检查，不要直接运行来源不明的动作脚本。
