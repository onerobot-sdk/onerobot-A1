机械臂安装 ​

安装前

安装全程保持断电，并确保机械臂与基座不会倾倒或坠落。安装完成后先清空工作空间，再上电和连接主机。

下面的演示视频完整展示了支架组装、机械臂固定、末端工具安装、接通电源和连接主机的过程。建议先看一遍视频，再对照实际物料操作。

安装前准备 ​

  • 按随箱清单核对物料与数量，确认型号（A1L / A1R）与安装位置一致。
  • 准备能够承受机械臂自重和运动反作用力的台面，并预留线缆走向空间。
  • 清空安装区域，避免安装过程中碰伤臂体或末端工具。

安装步骤 ​

  1. 组装支架。按视频把支架配件装到铝型材支架上，拧紧全部螺钉。
  2. 固定支架。用支架固定配件把支架固定在台面上，确认受力时无位移。
  3. 安装机械臂。断电状态下把机械臂装到支架上，确认连接件锁紧、臂体与周边无干涉。
  4. 安装末端工具。按实际配置安装夹爪或裸法兰；安装夹爪时先让夹爪端口、螺丝孔和线材在同一直线上，再拧紧螺钉。相关配置见 TCP、负载与末端工具。
  5. 连接电源。按安装视频连接 24V 电源线，线缆走向避开机械臂运动范围。
  6. 接线 USB-CAN 适配器。把机械臂 CAN 线的黑线接到 CANL，红线接到 CANH，GND 不接；USB 口插到电脑。
  7. 插入机械臂。把电源线与 CAN 线汇合后的另一端，对准机械臂与支架连接处下方的插孔插入。
  8. 上电前复查。确认固定件、线缆和工具均已锁紧，工作空间内无人员和障碍物。

接线图 ​

下图是 USB-CAN 适配器一端的接法：

  • 黑线 → CANL
  • 红线 → CANH
  • GND → 不接
  • USB 口 → 电脑
  • 电源线与 CAN 线汇合后的插头 → 机械臂与支架连接处下方的插孔

电源线的接法以页面顶部的安装教程视频为准。

WARNING

接口位置、线序与供电规格以随箱说明和产品手册为准，不要凭猜测接线；不要在带电状态下插拔 CAN 或电机线缆。

下一步 ​

安装完成后，按连接真机完成 CAN 映射、只读连接检查和 Debug UI 确认。
