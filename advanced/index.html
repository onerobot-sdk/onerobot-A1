示教、力控与标定 ​

示教、力控和标定都依赖正确的安装方向、工具参数与动力学模型，但三者目的不同。

功能目的主要接口
拖动示教手动引导机械臂并记录关节轨迹freedrive_enable()、start_recording()、replay()
力/位混合控制在选定方向施力，在其他方向保持位置force_mode()、force_mode_disable()
零位标定让指定机械姿态对应用户坐标零位set_current_position_as_zero()
动力学标定辨识惯性、重力和摩擦参数calibrate_dynamics()、load_calibration()
运动学标定修正模型参数，改善绝对定位一致性KinematicCalibrator
手眼标定求解相机与法兰或基座之间的变换OpenCV 手眼标定流程

真机操作提示

自由驱动和力控都会持续向关节发送力矩，不是断电、失能或紧急停止。错误的安装方向、负载、TCP、力方向或标定数据可能造成机械臂突然运动。真机验证时必须清空工作空间、限制人员接近并确保紧急停止可用；调用 disable() 前还要可靠支撑机械臂。

拖动示教与回放 ​

工作原理 ​

freedrive_enable() 在后台控制循环中计算重力补偿，并把关节位置增益设为零，使操作者可以手动引导机械臂。它仍然处于使能状态，并不是完全无力矩模式。

参数含义
damping关节阻尼；0 阻力最小，数值越大越难拖动
free_axes[x, y, z, rx, ry, rz]，1 表示允许运动，0 表示锁定；省略时全部自由
lock_stiffness受限自由驱动中锁定方向的位置增益

例如只允许 TCP 沿 Z 方向移动：

python
arm.freedrive_enable(
    damping=0.5,
    free_axes=[0, 0, 1, 0, 0, 0],
    lock_stiffness=200.0,
)

free_axes 使用机械臂基座坐标系方向。首次使用受限自由驱动前，应先确认安装方向和基座轴方向符合预期。

录制与回放流程 ​

python
arm.enable()

arm.start_recording()
arm.freedrive_enable(damping=0.5)
input("手动引导机械臂，完成后按 Enter：")
arm.freedrive_disable()
recording = arm.stop_recording()

print(f"{recording.num_frames} 帧，{recording.duration:.1f} 秒")
recording.save("my_trajectory.json")

# 首次回放使用较低速度和较长的起始过渡。
arm.replay(recording, speed_factor=0.5, lead_in=3.0)

推荐按以下顺序进行真机验证：

  1. 不录制轨迹，短时间进入自由驱动，确认机械臂不会明显上浮、下坠或振荡。
  2. 开始录制后缓慢拖动，避开关节极限、奇异位形和环境障碍物。
  3. 调用 freedrive_disable()；机械臂退出自由驱动并保持当前位置，但仍处于使能状态。
  4. 检查 num_frames >= 2 且 duration > 0，再保存轨迹。
  5. 清空整条轨迹的扫掠空间，先以 speed_factor=0.5 回放，确认后再考虑提高速度。

replay() 默认会先平滑移动到录制起点。首次回放不要设置 lead_in=0，否则当前位置与录制起点不同时可能产生突变。超过 1000 帧的长轨迹可使用 save_npz()，文件通常比 JSON 更小。

查看完整示教回放示例

回放不是重新规划

回放复现记录的关节轨迹，不会自动识别后来出现的障碍物，也不会因为换了工具、安装位置或工件而自动修正路径。环境或机械结构改变后必须重新验证。

异常退出处理 ​

示教代码应保证异常时先退出自由驱动，再根据机械臂是否受到支撑决定是否失能：

python
try:
    arm.freedrive_enable(damping=0.5)
    # 示教操作
finally:
    if arm.is_freedrive:
        arm.freedrive_disable()  # 退出示教并保持当前位置
    # 仅在机械臂受到可靠支撑时执行：
    # arm.disable()

freedrive_disable()、stop() 和 disable() 含义不同：前者退出自由驱动并保持当前位置，stop() 用于停止当前运动，disable() 撤销电机保持力矩。

力/位混合控制 ​

接口含义 ​

force_mode() 把笛卡尔方向分成力控方向和位置保持方向。它是单帧指令，需要在用户循环中按 arm.control_freq 持续调用，不像 movej() 一样自行执行一段完整运动。

python
arm.force_mode(
    selection=[0, 0, 1, 0, 0, 0],
    wrench=[0, 0, -1, 0, 0, 0],
    limits=[0, 0, 0.01, 0, 0, 0],
    frame="base",
)

参数含义
selection[fx, fy, fz, tx, ty, tz]；1 为力控方向，0 为位置保持方向
wrench目标力和力矩 [fx, fy, fz, tx, ty, tz]，单位为 N、Nm
limits力控方向的速度上限 [vx, vy, vz, wx, wy, wz]，单位为 m/s、rad/s
frame力和选择方向所属坐标系：base、world、tool 或已注册的自定义坐标系
kp、kd位置保持方向的增益和整体阻尼；首次测试保留模型默认值

设置 TCP 后，SDK 会计算 TCP 力到法兰力矩的力臂影响。使用 frame="tool" 前必须先调用 set_tcp()。旧参数 task_frame 仍可用，但新代码优先使用含义更明确的 frame；同时传入两者时以 task_frame 为准。

有限时长的安全调用框架 ​

下面的 1 N 和 0.01 m/s 只是说明参数格式，不是所有工具和接触面的通用安全值：

python
import time
from onero_sdk import ControlClock

period = 1.0 / arm.control_freq
deadline = time.monotonic() + 1.0
clock = ControlClock()

try:
    while time.monotonic() < deadline:
        arm.force_mode(
            selection=[0, 0, 1, 0, 0, 0],
            wrench=[0, 0, -1, 0, 0, 0],
            limits=[0, 0, 0.01, 0, 0, 0],
            frame="base",
        )
        clock.tick(period)
finally:
    arm.force_mode_disable()

force_mode_disable() 会退出力控并在当前位置恢复正常位置保持，不会让电机失能。

不是力传感器闭环

当前 force_mode() 根据动力学模型和雅可比矩阵把目标力映射为关节力矩；目标值不等于经过独立力传感器闭环保证的实际接触力。摩擦、负载误差、安装方向和环境刚度都会影响真实接触力，因此它不能替代碰撞安全认证或人员防护。

标定 ​

标定类型与适用范围 ​

类型输入数据输出与影响何时重做
软件零位机械臂处于已知机械基准姿态时的编码器值用户关节坐标偏移电机、减速器、联轴器或零位关系改变后
动力学标定多个静态构型及各关节正反向扫描惯性参数、库仑摩擦、黏性摩擦安装方向或机械结构发生变化后
运动学标定从多个构型接触同一固定参考点各关节原点的小幅位置修正机械结构拆装或精度复核不通过后
手眼标定多组法兰位姿和标定板相机位姿法兰到相机或基座到相机的变换相机、镜头、法兰或支架位置改变后

标定文件应与机械臂型号、左右侧、序列号、安装方向、工具、固件版本、SDK 版本和采集日期一起保存，不能在不同机械臂之间直接复用。

软件零位 ​

set_current_position_as_zero() 把当前实体姿态设置为新的用户坐标零位，并保存到：

text
~/.onero/zero_offsets/<model>_<channel>.json
1

执行前必须满足：

  • 使用定位销、工装或其他可复现基准确定机械零位，不能仅凭目测；
  • 机械臂已经可靠支撑并处于失能状态；
  • 所有关节完全静止，工装不会在读取过程中移动。
python
arm = Arm("A1R", channel="can0")

# 机械臂应已由工装固定在目标零位，并保持失能。
offsets = arm.set_current_position_as_zero(note="A1R 工装零位")
print(offsets)

该操作只修改 onero-sdk 的软件偏移，不会写入电机固件。clear_zero_offset() 同样要求机械臂处于失能状态，并会删除已保存的软件偏移。写入电机 Flash 属于难以恢复的设备级操作，不应作为常规标定步骤。

residual_rms 是力矩模型拟合残差，单位 Nm；较小通常表示采集数据与模型更一致，但不等于末端定位精度。加载时如果标定文件的重力方向与当前安装方向不一致，SDK 会给出警告，此时应重新标定。

运动学标定 ​

运动学标定使用单点约束法：让末端从不同关节构型接触同一个固定参考点，再优化各关节原点的小幅修正量。至少需要 4 组触点，实际建议采集 15～30 组、覆盖多种构型。

bash
pip install scipy
python examples/16_kinematic_calibration.py

真机使用核心流程：

python
from onero_sdk import KinematicCalibrator

calibrator = KinematicCalibrator.from_arm(arm)
for index in range(20):
    input(f"第 {index + 1}/20 次接触参考点后按 Enter：")
    calibrator.record_touch(arm=arm)

print(f"标定前位置分散度：{calibrator.get_spread_mm():.2f} mm")
result = calibrator.solve(max_correction_mm=5.0)
result.save("a1r_kinematic.json")
arm.apply_kinematic_calibration(result)

手眼标定 ​

腕部相机（Eye-in-Hand）需要求解：

text
T_base_camera = T_base_flange × T_flange_camera
1

推荐流程：

  1. 先完成相机内参和畸变标定。
  2. 固定标定板，在 10～20 个具有明显位置和朝向差异的机械臂姿态采集图像。
  3. 每次同步保存法兰位姿 T_base_flange 和标定板在相机中的位姿 T_target_camera。
  4. 使用手眼标定算法求解 T_flange_camera。
  5. 用未参与求解的数据检查重投影误差和机器人坐标转换误差。

示例数据边界

17_camera_calibration.py 演示坐标变换和求解流程，其中相机观测是模拟数据，预设的相机内参也只是示例值；它不是连接实际相机即可直接完成标定的程序。示例仍会连接 can0 并移动真机，运行前必须逐个校核全部关节目标。

常见问题 ​

现象优先检查
自由驱动明显下坠或上浮mounting、工具和工件质量、重心、夹爪补偿配置
自由驱动抖动或很难拖动damping 是否过大、负载参数是否错误、是否接近关节极限或奇异位形
回放开始时突然换位是否保留 lead_in、当前位置是否远离录制起点、是否使用了过高 speed_factor
力方向与预期不一致frame、TCP 姿态、安装方向以及 wrench 正负号
力控方向持续加速是否处于自由空间、是否设置对应方向的非零 limits、循环是否及时调用 force_mode_disable()
外力估计偏置较大动力学标定、负载和重心是否正确，机械臂是否静止，关节摩擦是否显著
标定残差异常样本是否足够且分布多样、参考点是否移动、安装方向和数据单位是否一致
