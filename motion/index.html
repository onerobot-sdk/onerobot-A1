接口总览 ​

Onero A1 的运动接口主要按“目标是什么”和“由谁推进控制循环”选择：SDK 可以完成整段目标或速度运动，应用也可以通过单帧接口自行驱动实时循环。

如何选择接口 ​

任务要求推荐接口关键区别
返回软件定义的关节零位home()本质上是预设零位目标的关节运动
到达指定关节角movej()约束关节目标，不保证 TCP 走直线
到达指定 TCP 位姿，不要求直线路径movep()先求终点 IK，再进行关节插值
TCP 沿直线运动movel()对完整直线路径逐点求解 IK
TCP 沿圆弧运动movec()由当前位置、经过点和终点定义圆弧
外部控制器逐帧生成目标servoj()、servop()每次调用只发送一帧，应用负责循环频率和超时
按关节速度或 TCP 速度运动一段时间speedj()、speedl()SDK 完成加速、保持和减速，调用期间阻塞
中断当前运动并减速到零stop()停止后保持当前位置，机械臂仍然使能

参数与控制节奏 ​

接口核心输入时间与速度参数调用节奏
home()无显式目标duration，可选 kp、kd调用一次，运动结束后返回
movej()joints：7 个关节角，单位 radduration，或 speed与 acceleration调用一次，运动结束后返回
movep()position、rotation、frameduration，或关节 speed与 acceleration调用一次，运动结束后返回
movel()、movec()TCP 位置、姿态和 frameduration，或工具 speed与 acceleration先检查路径 IK，再执行并阻塞到结束
servoj()joints，可选 velocities、kp、kd、tau_ff没有 duration应用按 arm.control_freq 持续调用
servop()position、rotation、frame，可选 kp、kd没有 duration应用按 arm.control_freq 持续调用
speedj()7 个关节速度，单位 rad/sacceleration、duration调用一次，减速到零后返回
speedl()[vx, vy, vz, wx, wy, wz]，单位 m/s、rad/s关节 acceleration 上限、duration调用一次，减速到零后返回
stop()无运动目标deceleration可从另一线程中断运动；停止后返回

使用这些参数时需要注意：

  • 目标运动同时传入 duration 和 speed 时，duration 优先；建议只选择一种时间约束。
  • speedj()、speedl() 未传 duration 时，默认在加速后保持目标速度 1 秒，再减速到零。
  • servoj()、servop() 停止发送新帧不等于执行受控停止；循环退出时必须显式设计 stop() 或应用层安全策略。
  • 阻塞式调用返回表示该运动过程已经结束，不代表实际位置与理想目标完全一致；应检查返回的 ArmState、get_state() 或 get_pose()。

真机发送目标前

核对机械臂型号、坐标系、TCP 和负载，检查起点到终点的完整路径，并提前确定数据中断或目标不可达时的停止方式。首次验证应先在 MuJoCo 中确认方向和路径，再使用小幅、低速真机目标。

更详细的接口说明见关节与笛卡尔运动和实时与速度控制，视频与完整代码见使用案例：运动控制。
