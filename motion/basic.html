关节与笛卡尔运动 ​

关节运动直接描述 7 个关节的目标，笛卡尔运动描述 TCP 的位置和姿态。二者不是“精度高低”的替代关系，而是分别约束不同的运动空间和路径特征。

movej()、movep()、movel() 和 movec() 均可通过 speed 和 acceleration 约束运动，也可改用 duration 指定期望运动时间。两种写法建议二选一；同时传入时 duration 优先。

接口speedacceleration
movej()、movep()最大关节速度，单位 rad/s关节加速度，单位 rad/s²；默认 1.4 rad/s²
movel()、movec()最大 TCP 线速度，单位 m/sTCP 线加速度，单位 m/s²；默认 1.2 m/s²

speed 是请求的速度上限，不保证短距离运动一定达到该速度。关节实际速度还会受到当前型号的逐关节速度上限和 SafetyConfig.max_velocity 限制，详见关节参数。

真机速度约束

speed 不是安全速度许可。真机运行前仍须根据工具、负载、安装方式和完整扫掠空间选择更低的初始速度，并确保紧急停止和断电措施可用。

movej ​

python
arm.movej(
    [0.0, -0.5, 0.3, -1.0, 0.0, 0.5, 0.0],
    speed=0.5,
    acceleration=1.0,
)

七个元素依次对应七个关节，单位为弧度。上例将最大关节速度约束为 0.5 rad/s、关节加速度约束为 1.0 rad/s²；如需按时间规划，可改为仅传入 duration=2.0。

movej() 更适合快速换位和姿态切换。末端在关节空间规划下通常不会沿直线移动，若工艺要求工具尖端必须沿直线，应改用笛卡尔接口并检查完整路径。

对应的关节运动代码和演示视频见使用案例：MoveJ。

movep ​

python
start_position, start_rotation = arm.get_pose(frame="world")
target_position = start_position.copy()
target_position[1] += 0.08

arm.movep(
    position=target_position,
    rotation=start_rotation,
    speed=0.5,
    acceleration=1.0,

movep() 先对目标 TCP 位姿求一次逆运动学，再对求得的关节目标执行关节空间插值。它适合只要求到达指定 TCP 位姿、不要求 TCP 中间路径为直线的换位任务；中间路径可能弯曲，不能把它当作 movel() 使用。

position、rotation 和 frame 的含义与其他笛卡尔接口一致。全零关节姿态接近奇异位形，示例会先使用 movej() 进入非奇异准备位。使用 speed 时，其含义是最大关节速度，单位为 rad/s；也可通过 duration 指定整段运动时间。

对应的点到点运动代码和演示视频见使用案例：MoveP。

笛卡尔运动依赖正逆运动学。运行前确认目标可达、姿态连续，并避开奇异位形。

position 和 rotation 应在同一个 frame 下表达。目标位姿不可达、姿态跳变或接近奇异位形时，运动可能失败、降速或出现较大的关节变化；这不是通过增大 duration 就能完全解决的问题。

对应的直线运动代码和演示视频见使用案例：MoveL。

movec ​

python
arm.movec(
    via_pose=[x_via, y_via, z_via, rx_via, ry_via, rz_via],
    target_pose=[x_target, y_target, z_target, rx_target, ry_target, rz_target],
    speed=0.05,
    acceleration=0.2,

movec 使用当前 TCP 位姿作为圆弧起点，再通过 via_pose 和 target_pose 定义经过点与终点。位姿格式为 [x, y, z, rx, ry, rz]，位置单位为米，旋转向量单位为弧度；示例保持末端姿态不变，在基座坐标系的 X-Z 平面执行圆弧。SDK 会在发送运动指令前检查路径点的逆运动学可达性。

圆弧的安全检查不能只看起点、经过点和终点，还要检查圆弧扫过的中间空间。工具长度、负载和姿态约束变化后，应重新评估路径。

对应的圆弧运动代码和演示视频见使用案例：MoveC。

多路点轨迹 ​

批量任务应先在仿真中检查所有路点，并为途经点设置合理的平滑参数。参见多路点轨迹。

接口选择示例 ​

任务推荐接口主要检查
快速移动到另一个关节姿态movej()关节限位、终点碰撞和姿态变化
到达指定 TCP 位姿，不要求直线路径movep()终点 IK、关节插值路径和环境碰撞
工具沿固定方向插入或靠近movel()TCP 路径、姿态连续性和奇异位形
绕工件边缘经过圆弧movec()中间路径、经过点和终点可达性
多个任务点连续执行TrajectoryPlanner 或多次目标运动轨迹融合、途经点停顿和最终停稳

接口核心输入主要反馈不能省略的检查

movel()位置、姿态、frameget_pose()TCP、IK 可达性、直线路径

阻塞式调用返回表示该调用的运动窗口结束，仍应结合反馈确认实际状态。一个最小的反馈读取方式如下：

python
state = arm.get_state()
position, rotation = arm.get_pose()
print("关节角：", state.joints)
print("TCP 位置：", position)
