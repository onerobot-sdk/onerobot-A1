关节与笛卡尔运动 ​

关节运动直接描述 7 个关节的目标，笛卡尔运动描述 TCP 的位置和姿态。二者不是“精度高低”的替代关系，而是分别约束不同的运动空间和路径特征。

movej ​

python
arm.movej(
    [0.0, -0.5, 0.3, -1.0, 0.0, 0.5, 0.0],
    duration=2.0,
)
1
2
3
4

七个元素依次对应七个关节，单位为弧度。duration 指定期望运动时间；也可使用 speed 和 acceleration 约束。

movej() 更适合快速换位和姿态切换。末端在关节空间规划下通常不会沿直线移动，若工艺要求工具尖端必须沿直线，应改用笛卡尔接口并检查完整路径。

movel ​

python
arm.movel(
    position=[0.30, 0.00, 0.20],
    rotation=[0.0, 0.0, 0.0],
    duration=2.0,
    frame="base",
)

笛卡尔运动依赖正逆运动学。运行前确认目标可达、姿态连续，并避开奇异位形。

position 和 rotation 应在同一个 frame 下表达。目标位姿不可达、姿态跳变或接近奇异位形时，运动可能失败、降速或出现较大的关节变化；这不是通过增大 duration 就能完全解决的问题。

movec ​

python
arm.movec(
    via_pose=[x_via, y_via, z_via, rx_via, ry_via, rz_via],
    target_pose=[x_target, y_target, z_target, rx_target, ry_target, rz_target],
    duration=5.0,
    frame="base",
)

movec 使用当前 TCP 位姿作为圆弧起点，再通过 via_pose 和 target_pose 定义经过点与终点。位姿格式为 [x, y, z, rx, ry, rz]，位置单位为米，旋转向量单位为弧度；示例保持末端姿态不变，在基座坐标系的 X-Z 平面执行圆弧。SDK 会在发送运动指令前检查路径点的逆运动学可达性。

圆弧的安全检查不能只看起点、经过点和终点，还要检查圆弧扫过的中间空间。工具长度、负载和姿态约束变化后，应重新评估路径。

对应的圆弧运动代码和演示视频见使用案例：运动控制。

多路点轨迹 ​

批量任务应先在仿真中检查所有路点，并为途经点设置合理的平滑参数。参见多路点搬运。

对应的基础关节、圆弧和位置控制视频见使用案例：运动控制。

接口选择示例 ​

任务推荐接口主要检查
快速移动到另一个关节姿态movej()关节限位、终点碰撞和姿态变化
工具沿固定方向插入或靠近movel()TCP 路径、姿态连续性和奇异位形
绕工件边缘经过圆弧movec()中间路径、经过点和终点可达性
多个任务点连续执行TrajectoryPlanner 或多次目标运动轨迹融合、途经点停顿和最终停稳

输入与反馈 ​

接口核心输入主要反馈不能省略的检查
movej()7 个关节角state.joints、state.torques关节限位和关节空间中间姿态
movel()位置、姿态、frameget_pose()TCP、IK 可达性、直线路径
movec()经过点、终点、frameget_pose() 与路径观察圆弧经过空间和中间姿态

阻塞式调用返回表示该调用的运动窗口结束，仍应结合反馈确认实际状态。一个最小的反馈读取方式如下：

python
state = arm.get_state()
position, rotation = arm.get_pose()
print("关节角：", state.joints)
print("TCP 位置：", position)
