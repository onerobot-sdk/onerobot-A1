实时与速度控制 ​

实时控制由调用方负责“每一帧发送什么、多久发送一次、异常时如何停止”。它适合视觉伺服、遥操作和外部规划器输出，不适合在没有频率控制和超时处理的脚本中直接试用真机。

servoj / servop ​

实时接口每次调用只发送一帧目标。调用方必须保持稳定频率，处理超时，并在循环退出时执行受控停止。

python
import math
import time

for step in range(500):
    t = step / 100.0
    q = [0.0] * 7
    q[1] = 0.2 * math.sin(2 * math.pi * 0.2 * t)
    arm.servoj(q)
    time.sleep(0.01)

sleep() 不能保证硬实时，真机部署应测量循环抖动，并按控制需求选择实时调度能力。

实时循环的最小要求 ​

  1. 固定目标发送频率，并记录实际循环周期。
  2. 为传感器、规划器和通信设置超时。
  3. 数据中断或循环退出时调用 stop() 或执行应用层安全策略。
  4. 不要把停止发送新目标理解为自动失能。

servoj() 和 servop() 是单帧接口，最后一帧目标的保持行为取决于后端和 SDK 版本；应用必须显式设计正常退出和异常退出路径。

  • servoj() 对应案例：ServoJ 实时关节伺服。

循环退出骨架 ​

实时控制逻辑应把“发送目标”和“退出处理”放在同一个控制边界内：

python
try:
    while controller.is_running():
        target = controller.next_target()
        arm.servoj(target)
        # 记录周期、反馈和数据源时间戳。
finally:
    arm.stop()

speedj / speedl ​

speedj 和 speedl 分别控制关节速度和笛卡尔速度。速度方向、持续时间和加速度共同决定运动距离，运行前应根据当前姿态估算是否会进入限位或碰撞区域。

指定目标速度后，机械臂以设定的加速度平滑加速到目标速度，到达指定时间后减速停止。

速度控制控制运动速度而非位置时使用，不保证自然返回精确终点。需要精确到位时使用 movej 或 movel。

对应的实时伺服和速度控制视频见使用案例：运动控制。

实时接口的监控项 ​

项目应观察的信号异常时的优先动作
控制周期实际周期、抖动、超时次数停止下发新目标并执行受控停止
目标数据时间戳、数组长度、范围丢弃异常数据，不要继续复用未知目标
机械臂反馈位置、速度、力矩、通信状态停止运动并保留日志
外部控制器相机、遥操作器或规划器在线状态进入应用层安全退出路径

速度接口同样需要这些监控项。即使指定了 duration，也应把实际反馈和停止逻辑作为任务完成条件的一部分。
